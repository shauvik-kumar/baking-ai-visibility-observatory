# Baking AI Visibility Observatory

Research project studying how search engines and AI systems answer real-world baking, bakery, cake, recipe, baking-class, product, and local-bakery questions over time.

## Current Phase

Phase 1 — Smallest Working Prototype

- 10 controlled baking questions
- 1 AI/search engine
- Raw response capture
- Timestamped observations
- Historical storage
- Run-to-run comparison

## Current Engine

Gemini API — initial research engine.

## Project Principles

- ₹0 / near-zero-cost first
- Raw research data is preserved
- Historical observations are never overwritten
- Same query wording is used for controlled experiments
- No scraping that bypasses restrictions
- No private user data
- No API credentials committed to GitHub
- Build incrementally
- Validate before expanding
